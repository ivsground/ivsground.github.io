# IVSGround Project Page

Project page for **"Where to Look Matters: Learning Influential Views for VLM-based 3D Visual Grounding"** (ECCV 2026).

- `index.html` - main project page (abstract, method figures, video, BibTeX)
- `demo/` - interactive Three.js demo (scene point clouds, view-selector rankings, VLM reasoning)
- `static/` - images, videos, CSS

## Interactive demo data

`demo/data/` (6 scenes, 34 queries) is generated by `demo/export_scene_data.py`
in the code repo; generation scripts and input locations are documented there.

## Local preview

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

The demo subpage requires a web server (fetches JSON/PLY); opening `index.html` via `file://` works only for the main page.

## Deployment

GitHub Pages (static). Push to `main`, then enable Pages: Settings -> Pages -> Deploy from branch -> `main` / root.
